# Dataset

The original study used the public [ICU Patient Monitoring and Mortality Prediction dataset](https://www.kaggle.com/datasets/jayjoshi37/icu-patient-monitoring-and-mortality-prediction), comprising **15,000 patient records** and **24 initial variables**. The classification outcome is `mortality_label` (0 = survived, 1 = died). The final study uses seven selected predictors.

The large CSV is **not duplicated in this standalone repository**. Download the [source CSV from the original team repository](https://github.com/M1sh13l/ICU-Mortality-Prediction-ML/blob/main/data/ICU_Patient_Monitoring_Mortality_Prediction_15000.csv) or obtain it through Kaggle; follow the notebook's data-loading instructions. Check the dataset's original terms before redistribution.
