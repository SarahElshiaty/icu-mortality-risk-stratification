# Dataset

The project uses the public [ICU Patient Monitoring and Mortality Prediction dataset](https://www.kaggle.com/datasets/jayjoshi37/icu-patient-monitoring-and-mortality-prediction), with 15,000 records and 24 initial variables. Seven predictors were used in the final study.

The original CSV is available [here](ICU_Patient_Monitoring_Mortality_Prediction_15000.csv). Dataset origin and usage terms remain with its original provider.
